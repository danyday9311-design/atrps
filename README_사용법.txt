공수 취향표 11페이지 버전

파일 업로드 위치: GitHub 저장소 최상위(root)
필수 파일: index.html, style.css, app.js

구성
- 한 사람이 11개 작성 페이지를 순서대로 작성
- 각 페이지에 이름, 프로필 사진, L–R 취향 선택, 150자 의견 입력
- 이전/다음 이동 및 마지막 페이지에서 최종 결과 확인
- 최종 결과는 참고 이미지 2처럼 3열 카드형 레이아웃
- PNG 저장
- 작성 내용은 현재 브라우저에 자동 저장

사용
1. 페이지 1부터 11까지 순서대로 작성합니다.
2. 마지막 페이지에서 '최종 결과 보기'를 누릅니다.
3. PNG 이미지 저장을 누르면 결과표를 저장할 수 있습니다.

수정
- 상단 &TEAM 텍스트는 직접 수정할 수 있습니다.
- 각 페이지의 멤버 이름과 사진을 변경할 수 있습니다.
- 디자인은 style.css에서 변경할 수 있습니다.

주의
자동 저장은 현재 기기의 현재 브라우저에만 적용됩니다. 다른 사람과 작성 내용을 실시간 공유하거나 서버에 전송하지 않습니다.
